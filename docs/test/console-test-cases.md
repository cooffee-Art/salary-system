| I18N-04 | 中文无乱码 | 中文全流程 | 中文正常显示，无方块/问号 | 黑盒 |

| I18N-06 | 语言包 key 完整 | 15 个关键 key（登录、权限、校验） | 中英各一份，无 `!key!` 占位 | 白盒 |

> 中文 Windows 下若重定向输出看到乱码，是终端代码页问题：先 `chcp 65001`，或运行时加 `-Dstdout.encoding=UTF-8`（Java 18+ 的 `file.encoding` 不再决定 stdout 编码）。见报告“环境说明”。
